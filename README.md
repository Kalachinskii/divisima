# Divisima Shop

Сайт представляет собой полнофункциональный интернет-магазин одежды и аксессуаров с административной панелью управления.

- Проект реализует полный цикл электронной коммерции:
  - Каталог товаров с фильтрацией и поиском
  - Система корзины и оформления заказа
  - Пользовательские аккаунты и личный кабинет
  - Административная панель для управления контентом

Проект демонстрирует навыки full-stack разработки с использованием современных веб-технологий.

## Функциональность

- **Публичная часть:**

  - Каталог товаров с категориями и фильтрами
  - Корзина покупок с добавлением/удалением товаров
  - Регистрация и авторизация пользователей

- **Административная панель:**
  - Управление товарами (добавление, редактирование, удаление)
  - Управление категориями и подкатегориями
  - Просмотр и обработка заказов
  - Управление пользователями

## Стек технологий

- **Backend:** PHP 7.4
- **База данных:** MySQL
- **API:** REST API
- **Frontend:** JavaScript (нативный), HTML5, CSS3
- **Административная панель:** Кастомная разработка на PHP/JavaScript
- **Развертывание:** Веб-сервер с поддержкой PHP и MySQL

## Установка и запуск

Для запуска проекта локально вам потребуется веб-сервер с поддержкой PHP и MySQL.

**Рекомендуемое окружение:**
Open Server Panel 5.4.3 (проект оптимизирован для этой версии, не использует PHP 8, легко настраивается)

_Альтернатива:_ свежая версия Open Server или другой веб-сервер (потребует дополнительных настроек)

1.  **Установите Open Server:**

    - Скачайте и установите Open Server Panel 5.4.3
    - Запустите Open Server и активируйте сервер
    - В настройках выберите модули: PHP 7.4 и MySQL

2.  **Откройте папку доменов:**

    - Перейдите в папку `OpenServer/domains/`

    - Быстрый способ: в адресной строке проводника замените полный путь на cmd и нажмите Enter

    _Пример: вместо C:\OpenServer\domains введите просто cmd_

3.  **Склонируйте репозиторий:**

    ```bash
    git clone https://github.com/Kalachinskii/divisima.git
    ```

4.  **Настройте базу данных:**

    - Откройте панель Open Server → "Дополнительно" → "PHPMyAdmin"
    - Создайте новую базу данных с именем `divisima`
    - Импортируйте файл `divisima.sql` из корня проекта

5.  **Настройте подключение к БД:**

    - Отредактируйте файл `app/config/db_config.php`
    - Убедитесь, что данные подключения совпадают с вашим окружением.

6.  **Запустите проект:**

    В панели Open Server выберите ваш сайт в меню "Мои сайты"

7.  **Доступ к админ-панели:**
    - Перейдите по адресу `/admin`
